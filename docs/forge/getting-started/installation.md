## Install

**macOS:** open **Self Service**, search for **dongle**, and click
**Install**.

**Windows:** open **Company Portal**, search for **dongle**, and click
**Install**.

## Check the installation

Open a **new** terminal and run:

```sh
dongle --version
```

If dongle isn't found, close the terminal, open a new one and try again.
If it still isn't found, see [Troubleshooting](../troubleshooting/troubleshooting.md).

Running this command also starts dongle's one-time setup, which is the next
step.

## Update dongle

Use the same portal: open **Self Service** (macOS) or **Company Portal**
(Windows), find **dongle**, and click **Update** (or **Reinstall**) when a
new version is available. Your installed plugins are kept.
